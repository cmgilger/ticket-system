# ticket-system

Web-based ticketing system consisting of a public frontend and an admin-only backend.

## Components

### 1. Frontend

Publicly accessible front-end, designed to welcome users and intake their Name, Phone Number, Email, and their request.

### 2. Backend

Repository for e-tickets, sorted by date and with an option to reply that opens up a gmail client and begins writing an email.
